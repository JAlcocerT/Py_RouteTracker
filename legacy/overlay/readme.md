# Archived overlay scripts

The original prototype scripts this project's telemetry-overlay logic was ported from.
Kept for history; not maintained. **The actual way to use this project is `../../backend/`
+ `../../frontend/` — see the root `README.md`.**

- `racing_hud_v7.py`, `lap_timer_v7.py`, `circuit_mapper_v3.py`, `render_overlay.py` — the
  final, most-complete iterations, and the ones the webapp backend (`../../backend/app/`) was
  ported from. `notes.md` is the original author's running log of ffmpeg commands and design
  notes for these.
- Everything else here (`racing_hud.py` → `v6b`, `lap_timer.py` → `v6`, `circuit_mapper.py`/
  `v2`, plus one-off g-force/debug scripts) is superseded iteration that led up to the v7
  scripts above, plus their generated PNG/GIF artifacts.
