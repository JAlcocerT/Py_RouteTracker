# Archived overlay script versions

Superseded iterations of the video-telemetry-overlay scripts (`racing_hud.py` → `v6b`,
`lap_timer.py` → `v6`, `circuit_mapper.py`/`v2`, plus their one-off g-force/debug scripts and
generated PNG/GIF artifacts). Kept for history; not maintained.

The current reference implementation lives in `../../overlay/` (`racing_hud_v7.py`,
`lap_timer_v7.py`, `circuit_mapper_v3.py`, `render_overlay.py`), and the actual way to use
this project going forward is `../../webapp/`.
